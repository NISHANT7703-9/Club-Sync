# Club Sync

### Campus Club Management and Recommendation System

Club Sync is a Python-based application designed to help university students discover clubs, explore campus events, and connect with student communities according to their interests.

The project aims to simplify club discovery and improve communication between students and club leaders through a centralized system.

## Objectives

- Simplify club discovery for students.
- Provide club recommendations based on student interests.
- Manage club events and announcements.
- Maintain student and club information.
- Create a centralized platform for campus club activities.

## Features

- Student registration and login
- Club information management
- Interest-based club recommendations
- Event management
- Notices and announcements
- Student shortlist functionality
- Club leader functionalities

## How to Run

1. Download or clone this repository.
2. Install Python on your system.
3. Open the project folder in VS Code.
4. Run the main Python file.

```bash
python main6.py
```

## Purpose

Club Sync addresses the difficulty students may face in discovering university clubs, finding activities matching their interests, and accessing club-related information in one place.
